  [  high] metrics.sharpe  (p9)
           issue   : The paper's Sharpe is geometric: (CAGR - compounded fed funds CAGR) / annualised vol. This is NOT the conventional arithmetic-excess Sharpe. The paper itself quotes both (1.08 vs 1.08 for Markowitz, 0.60 vs 0.56 for 60/40).
           resolved: Replicate the geometric definition as primary; always compute and report the conventional one alongside. Targets below are pinned to the geometric basis.
  [  high] signal.lookback_days  (p7)
           issue   : The 11-day volatility/covariance window was chosen "after a modest search over various values" and is acknowledged as noisy. That search used the full 20-year sample, so the headline number is in-sample at the hyperparameter level.
           resolved: Replicate at 11 days to match the paper, but treat the result as in-sample and inflate the trial count for the deflated Sharpe ratio. Report a lookback sweep.
  [  high] portfolio.target_vol  (p10)
           issue   : The 7% target is asserted, not derived. Section 3.4 then sweeps 3%-12% in 0.5% steps -- 19 further configurations on the same sample.
           resolved: Treat 7% as the paper's headline and count the full sweep in the trial budget.
  [  high] costs.cost_model  (p27)
           issue   : Appendix A charges cost only on changes in NON-CASH weights: "moving value into or out of cash is not itself a trade". Volatility control works precisely by moving into and out of cash, so its main activity is free by construction.
           resolved: Replicate as specified to match the paper, then re-run charging cash moves as trades and report the difference as a named sensitivity. Do not merge the two.
  [medium] signal.cov_estimator  (p8)
           issue   : A 3x3 covariance matrix has 6 free parameters and is estimated from 11 daily observations. This is near-degenerate; the risk constraint it feeds is noisy.
           resolved: Replicate as specified, with a PSD projection before the solver, and record the solver-failure count as a diagnostic rather than hiding fallbacks.
  [  high] universe.cash_asset  (p9)
           issue   : The fed funds rate is used both as the Sharpe numeraire and as the yield the portfolio actually earns on cash. No investor earns DFF on a cash balance.
           resolved: Replicate as specified; flag that realised cash yield would be lower and that this flatters every cash-holding portfolio, which is all the winners.
  [medium] signal.alpha_source  (p28)
           issue   : The forecast target is a 100-day FORWARD return. Causality rests entirely on the training set ending at t-100. An off-by-one here would inflate every result.
           resolved: Implement with the stated t-100 cutoff and verify with an explicit look-ahead tripwire against same-bar returns before trusting any output.
